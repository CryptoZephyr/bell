## Defects found

- DEF-01 (S1): a paid order can show Refunded when a chain's payout logs cannot be read. Cause: decideOutcome in frontend/src/chain/payouts.ts returns refunded without checking that the read was complete.
- DEF-02 (S1): Unichain log reads fail with 'block range extends beyond current head block' because toBlock comes from the state RPC (publicnode) while logs go to the official RPC, which is 1 to 2 blocks behind. Seen as Unichain 'Nothing to pay', tickets 'Finished', and DEF-01. Fix: clamp toBlock to the log RPC's own head in logClient (frontend/src/chain/clients.ts), and show 'Checking payouts' when a read fails.
